# California Housing Price Prediction Using Machine Learning

## Project Overview

This project focuses on predicting California housing prices using Machine Learning regression algorithms.

The main goal is to build, evaluate, and improve regression models that can estimate median house values based on different housing features.

The project includes:

- Exploratory Data Analysis (EDA)
- Data Cleaning
- Outlier Detection and Removal
- Feature Engineering
- Feature Selection
- Feature Scaling
- Regression Model Development
- Model Comparison
- Hyperparameter Optimization


---

# Dataset

The project uses the **California Housing Dataset**.

The dataset contains information about housing blocks in California, including:

- Median income
- Housing age
- Total rooms
- Total bedrooms
- Population
- Households
- Latitude
- Longitude
- Median house value (Target Variable)
